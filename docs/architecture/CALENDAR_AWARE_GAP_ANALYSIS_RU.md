# Календарно-осведомлённый контроль пропусков

Добавлен `ExpectedCandleSchedule` — контракт для календаря конкретного рынка/доски/таймфрейма. Календарь возвращает ожидаемые начала свечей в запрошенном диапазоне с учётом торговых сессий, аукционов, праздников и внутридневных перерывов.

`CandleGapAnalyzer` сравнивает фактические timestamp с календарным расписанием. Пропуском считается только ожидаемая, но отсутствующая свеча. Неожиданные timestamp также выводятся отдельно для диагностики. Дубликаты timestamp не увеличивают число пропусков.

Если календарный адаптер или границы диапазона отсутствуют, результат остаётся `UNKNOWN`: `gapCount = null`, а не ноль. Это предотвращает ложное утверждение о полноте данных.

Важно: в этом изменении реализован интерфейс и проверяемый алгоритм, но не объявляется готовым производственный календарь MOEX. До подключения и верификации календарных данных для каждого рынка gap detection должен оставаться UNKNOWN.

# Backtesting core — breakout v1

## Назначение и границы

Первый детерминированный симулятор для стратегии пробоя 20 свечей с подтверждением относительным объёмом. Движок long-only, одновременно держит не более одной позиции и не отправляет брокерские заявки. Это технический этап, а не подтверждение доходности стратегии.

## Модель сделки

- Сигнал рассчитывается только после закрытия свечи.
- Вход выполняется не ранее открытия следующей свечи.
- Стоп: 2 ATR(14) ниже фактической цены входа.
- Цель: 2R от цены входа (отношение прибыль/риск 2:1).
- Размер позиции: риск-бюджет 1% текущего денежного остатка, с округлением вниз до целого числа лотов и ограничением доступным капиталом.
- Если на следующей свече открытие не позволяет купить хотя бы один лот, вход отклоняется.
- При касании стопа и цели внутри одной OHLC-свечи используется консервативное допущение: сначала сработал стоп.
- При гэпе через уровень выход моделируется по цене открытия, если она хуже стопа/лучше цели.
- Открытая позиция закрывается по последнему доступному Close в конце истории.

## Издержки

Комиссия по умолчанию 0,05% на каждую сторону сделки. Проскальзывание по умолчанию 5 базисных пунктов на каждую сторону. Оба параметра настраиваются. Комиссии и проскальзывание вычитаются из финансового результата.

## Метрики

Win Rate, средняя прибыль, средний убыток, Expectancy, Profit Factor, максимальная просадка и итоговая доходность. Просадка рассчитывается по ежедневной/свечной mark-to-market оценке на закрытии каждой свечи.

## Данные и ограничения

- Свечи должны быть в строгом хронологическом порядке и иметь валидные OHLC. Пропуски OHLC не заменяются нулями: входные данные отклоняются.
- Отсутствующий объём означает, что стратегия не подтвердит сигнал на этом баре.
- Текущая сигнальная свеча не используется для уровня пробоя и среднего объёма, а исполнение сигнала — только на следующем Open.
- Исторический диапазон, gaps и freshness должны проверяться вызывающим слоем по MOEX ISS / Room coverage перед запуском.
- В этой версии ещё нет календаря торговых сессий, праздников, специальных режимов, short/futures contract specification, funding/margin, частичных исполнений и проскальзывания по стакану. До добавления MOEX session calendar результаты являются предварительными и не должны считаться полноценным торговым backtest.
- Не следует сравнивать результаты разных инструментов без учёта лота, шага цены, валюты расчёта и спецификации контракта.

4. Добавить разбиение in-sample / out-of-sample и walk-forward.
5. Сверить расчёты на независимых тестовых наборах и проверить пограничные случаи.

# Адаптер машиночитаемого календаря MOEX

## Назначение

Добавлен read-only адаптер для чтения таблиц торговых дней и расписания сессий фондового и срочного рынков:

- `calendars/stock` — торговые дни фондового рынка;
- `calendars/stock/session` — расписание периодов по режимам;
- `calendars/futures` — торговые дни срочного рынка;
- `calendars/futures/session` — расписание периодов срочного рынка.

Запросы ограничиваются датами `from` и `till`; для расписания можно передать `secid` и `boardid`.

## Форматы

Для фондового рынка `time_from` и `time_till` могут содержать время внутри `tradedate`. Для срочного рынка поля расписания содержат дату и время. Парсер сохраняет тип периода и идентификаторы инструмента/режима.

Значение `is_traded = null`, отсутствующая строка или неполное расписание не интерпретируются как выходной день.

## Ограничения доступа

MOEX описывает машиночитаемый календарь как отдельный информационный сервис, доступный через ISS в составе ALGOPACK либо по отдельным условиям. Наличие URL не доказывает публичный доступ. Адаптер использует текущий HTTP-клиент приложения и намеренно не добавляет ключ или токен. HTTP 401/403 и прочие ошибки передаются вызывающему слою.

## Что пока НЕ реализовано

- Нет подтверждённого успешного live-запроса из Android-приложения или CI.
- Нет автоматического fallback на выдуманное расписание.
- Нет генерации ожидаемых свечей по периодам сессий: типы аукционов, клиринга и дискретных аукционов требуют отдельной валидации.
- Индексы не подключены: требуется проверить их соответствие фондовому календарю и конкретным режимам.
- Нет сохранения календаря в Room и привязки к gap/freshness evaluator.

До прохождения live smoke test календарь должен считаться неизвестным, а gap/freshness оставаться `UNKNOWN`.

## Проверка

Unit tests проверяют разбор форматов времени фондового и срочного рынков и сохранение неизвестного флага торгового дня. Эти тесты не подтверждают сетевой доступ к сервису MOEX.

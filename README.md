# MOEX Trading Lab

Самостоятельное Android-приложение для анализа Московской биржи, поиска торговых возможностей, тестирования стратегий и ведения журнала сделок.

## Основные параметры

- Android, Kotlin, Jetpack Compose
- Локальное хранение: Room
- Рынки: акции, фьючерсы и индексы Московской биржи
- Рыночные данные: MOEX ISS как основной источник
- Графики: Advanced — свечи, объёмы, индикаторы и инструменты анализа
- История: максимально доступная для каждого инструмента и интервала
- Начальный экспериментальный капитал: 1 000 ₽
- Торговые идеи формируются приложением; решения и исполнение остаются за пользователем
- Автоматическая отправка брокерских заявок не допускается

## Статус

Проект находится на начальном этапе. Техническое задание, архитектура и реализация будут добавляться в рабочих ветках и проходить проверку через Pull Request.

## Правила разработки

- Не изменять `main` в ходе обычной разработки.
- Работать в отдельных feature-ветках и открывать Pull Request.
- Не объединять Pull Request без явного разрешения владельца проекта.
- Проверять изменения тестами и сборкой.
- Не подменять отсутствующие рыночные данные нулевыми или фиктивными значениями.

# Доверие TLS для MOEX ISS в Android

## Причина

В августе 2026 года Московская биржа объявила переход интернет-сервисов, включая API, на сертификаты Национального удостоверяющего центра Минцифры России. Без корневого сертификата часть стандартных TLS-хранилищ отклоняет цепочку ISS.

## Реализация

- В `app/src/main/res/raw/russian_trusted_root_ca.pem` включён публичный корневой сертификат Russian Trusted Root CA.
- `network_security_config.xml` добавляет этот корень только для `iss.moex.com` и сохраняет системные доверенные корни.
- Для остальных доменов продолжают использоваться системные сертификаты Android.
- Обычная проверка имени хоста и TLS остаётся включённой. Запросы по HTTP не разрешаются.
- Не используются `--insecure`, отключение проверки сертификата, trust-all менеджеры или certificate pinning.

## Источник сертификата

Официальная инструкция MOEX направляет за корневым и выпускающим сертификатами на Госуслуги: https://www.gosuslugi.ru/crt

В CI архив скачивается с официального CDN портала:
`https://gu-st.ru/content/lending/windows_russian_trusted_root_ca.zip`

Перед установкой проверяются субъект сертификата (Russian Trusted Root CA) и признак CA:TRUE. Сертификат имеет срок действия до 27.02.2032. В тестовом контуре после установки корня HTTPS-запросы к каталогам и свечам MOEX ISS прошли со стандартной проверкой TLS; сервер передаёт необходимую промежуточную цепочку.

## Проверки

Live smoke workflow:
- устанавливает корневой сертификат в хранилище Ubuntu runner;
- проверяет каталоги акций, фьючерсов и индексов;
- проверяет 12 сочетаний трёх репрезентативных инструментов и четырёх интервалов;
- проверяет offset-пагинацию на SBER 1 минута.

При смене корневого или промежуточного сертификата необходимо повторить live-проверку и обновить ресурс Android из официального источника. Не скачивать сертификаты из сторонних зеркал.
